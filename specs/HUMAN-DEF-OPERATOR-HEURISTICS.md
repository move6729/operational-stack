## III. OPERATIONAL HEURISTICS (THE 5 BIOLOGICAL INVARIANTS)

### 1. Hard Asynchronous Batching (Communication Air-Gap)
- **Invariant:** Never maintain open real-time communication backchannels (Slack, Discord, Email, Messaging).
- **Execution:** Restrict incoming state updates to two fixed daily execution windows ($\Delta t = \text{08:00}, \text{17:00}$). Convert all incoming communications into static AST task structures or discard them.

### 2. Elimination of Conversational Interfaces (Axiom 4 Applied)
- **Invariant:** Treat interactive LLM chatboxes as high-entropy cognitive traps.
- **Execution:** Interact with computational runtimes exclusively via structured files (JSON, Markdown specs, Code Diff files). Never engage in conversational dialogue with inference engines.

### 3. Physical Silicon Isolation (Circadian Air-Gap)
- **Invariant:** Total physical removal of computational hardware from sleep and rest quarters.
- **Execution:** No silicon screens, wireless transmitters, or notification devices allowed within the physical sleep boundary. Re-establish natural circadian recovery cycles.

### 4. Ground-Truth Physical Anchoring (Atoms Over Tokens)
- **Invariant:** Validate operational success strictly through physical state changes, not digital status metrics.
- **Execution:** Allocate a minimum 30% of daily operator energy to physical world actions: hardware maintenance, manual agriculture, local machining, or physical conditioning.

### 5. Analog State Serialization (Paper Exocortex)
- **Invariant:** Primary system state and task DAGs must be serializable on physical paper.
- **Execution:** Maintain a physical notebook logging system invariants, critical cryptographic key hashes, and high-level strategy. If power or network access is severed, the operator's mental model remains fully intact.
