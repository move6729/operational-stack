$$E_{\text{Landauer}} = k_B T \ln 2$$

$$E_{\text{Landauer}} = \left(1.380649 \times 10^{-23}\text{ J/K}\right) \times 300.0\text{ K} \times 0.69314718 = 2.87049 \times 10^{-21}\text{ J/bit}$$
