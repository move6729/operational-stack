I. THE ASYMPTOTE OF SWITCHING COSTS
--------------------------------------------------------------------------------
For twenty years, the enterprise software industry operated on a single economic mechanism: high switching costs ($C_s \to \infty$).

Software cartels built billion-dollar business models not by offering superior computational mechanics, but by locking customer data inside proprietary database dialects, enforcing custom API wrappers, charging per-seat or per-student licensing fees, and taking 20% to 30%+ platform tolls on routine economic transactions.

When human developers write code by hand, migrating away from legacy software is a multi-million-dollar, multi-year nightmare. Enterprise platforms like Salesforce, SAP, Epic Systems, and Okta rely on this friction to extract persistent middleman rents.

In 2026, autonomous software agents and local bare-metal runtimes (LMCI-v1.0) have inverted this dynamic.

When an autonomous agent can ingest an entire legacy database, extract its underlying entity relationships, convert the state into an open JSON-LD graph, and execute refactored logic locally at silicon speed, software switching costs collapse to absolute zero:

    Lim_{A_p -> 1.0} SwitchingCost(A_p) = 0 ===> Vendor Margin -> Cost of Compute (Watts)

When switching costs decay to zero, the SaaS tollbooth evaporates. Software syntax becomes a fluid, temporary intermediate representation, and enterprise platforms lose their capacity to lock in customers.

III. THE BARE-METAL EXECUTION ARCHITECTURE
--------------------------------------------------------------------------------
These fifteen protocols are not abstract concepts. They run on a four-tier sovereign execution stack:

1. Zero-C2 Task Graph Scheduler (ATN-v1.0):
   Autonomous agents coordinate work asynchronously using static Directed Acyclic Graphs (schema/task_graph.json) and SHA-256 target state hashes, burning zero tokens on performative English chat.

2. Local Weight & Context Isolation (LMCI-v1.0):
   Inference executes offline on local bare-metal silicon (Apple Silicon, edge GPUs) using open-weight quantized models (GGUF/EXL2). Zero data fallback to commercial cloud APIs.

3. Local Mesh Transport Shielding (LMTI-v1.0):
   Outbound network frames bypass DNS using direct cryptographic key identities (WireGuard/Yggdrasil), padded to uniform 1024-byte blocks with egress timing jitter to neutralize Deep Packet Inspection (DPI).

4. Scavenged Edge Hardware Orchestration (EWASTE-v1.0):
   Aggregates scavenged consumer silicon and legacy edge devices into localized, solar-powered compute networks operating at raw electricity cost ($OpEx \to \text{Watts}$).
